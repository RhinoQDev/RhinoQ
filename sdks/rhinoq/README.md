# RhinoQ Node.js package

This is the unscoped npm distribution alias for `@rhinoq/node`.

Latest verified npm prerelease: `v0.1.0-beta.12`.

```bash
npm install rhinoq pg
npx rhinoq init
```

The scoped package remains available for applications that depend on the
library directly:

```bash
npm install @rhinoq/node pg
```
