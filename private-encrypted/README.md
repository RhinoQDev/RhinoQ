# Encrypted internal research

The `.rqe` files in this directory are authenticated AES-256-CBC-HMAC-SHA256
envelopes generated by
[`scripts/protect-private-research.ps1`](../scripts/protect-private-research.ps1).
They contain unpublished product and competitor research and are safe to keep
under version control only because the key is not in this repository.

The key is created locally at `private/research-key.txt`, which is ignored by
Git. Back it up in a password manager or private secret store. Losing it makes
the encrypted files unrecoverable.

Protect the local plaintext files:

```powershell
pwsh -File .\scripts\protect-private-research.ps1 -Mode protect
```

Restore them locally when needed:

```powershell
pwsh -File .\scripts\protect-private-research.ps1 -Mode restore
```

Never commit `private/research-key.txt` or the restored plaintext files.
