# AI Project Memory

Thư mục này là bộ nhớ vận hành cho AI và người phát triển. Đây không phải nơi chứa prompt tạm thời; mọi quy tắc ở đây phải ngắn, kiểm chứng được và được review như code.

| File                    | Vai trò                                             |
| ----------------------- | --------------------------------------------------- |
| `PROJECT_CONTEXT.md`    | mục tiêu, phạm vi, thuật ngữ và trạng thái hiện tại |
| `ARCHITECTURE_RULES.md` | invariant không được phá                            |
| `WORKFLOW.md`           | quy trình AI từ nhận task đến handoff               |
| `DEFINITION_OF_DONE.md` | điều kiện hoàn thành                                |
| `RELEASE_CHECKLIST.md`  | gate phát hành                                      |
| `DECISIONS.md`          | quyết định kiến trúc có lý do                       |
| `TASK_TEMPLATE.md`      | template task cho AI                                |
| `INCIDENT_TEMPLATE.md`  | template sự cố và postmortem                        |
| `CHANGELOG_POLICY.md`   | cách ghi thay đổi                                   |
